lib

The feces library only provides 3 functions

  • new -- creates new feces class
  • combine -- combines Changes and Deletes objects into one Applyable per player
  • reserve -- creates a Group structure that can be used by any feces object

Also, combine and reserve can both be used from an instance of feces via feces.combine and feces.reserve respectively (using . operator instead of :)

Functions​

new​

</>
lib.new(
jecs: Jecs,--

The jecs module instance (require("@rbx/jecs")).

world: World,--

The jecs.World instance to observe and mutate.

group?: Group,--

Optional initial group to use for the returned instance (creates default group).

debugPrints?: boolean--

Enable debug printing.

) → feces--

Returns a new feces instance.

Creates a feces library instance that watches the supplied world for component changes and exposes apply, delta, full, reserve, and other helpers. 

-- may be used like this in a module of its own
local world = jecs.world()
local feces = lib.new(jecs, world)

combine​

</>
lib.combine(
changes: Changes,--

The changes object returned from delta.

deleted: Deletes?--

Optional deletes object returned from delta.

) → {[Player]: Applyable}--

Per-player packets prepared from the changes+deletes.

combine translates Changes objects into per-player Applyable packets, ready to be serialized or sent to each client as one object with all the necessary updates. See the simple setup here.

reserve​

</>
lib.reserve(
size: number,--

number of lookup slots to reserve

debugLocation: boolean?--

whether to use debug.info for debugging

) → Group--

A Group object with its own lookup space.

Reserves a lookup namespace of size entries and returns a Group. The returned Group can be passed to lookup, ref, delta, apply, etc., to isolate replication to that namespace. Use feces:setGroup to add a particular entity to a replication group.

The primary goal of these is to allow serializing entites of specific types with a set amount of bits. So for example, you could have a maximum of 8 racecars at a time in your racing game, and you could create a replication group with a size of 8, and then serialize those entities' lookup ids as 3 whole bits.

Or if you're feeling fancy you can reserve a group then create an instance of feces from it:

local group = lib.reserve(24)
lib.new(jecs, myWorld, group)
