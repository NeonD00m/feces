feces

The feces class for replicating jecs entities and components.

Properties​

_debug​

</>
feces._debug: boolean?

When true, the library prints debug traces using feces:debug. This is intended to be set by new but I guess you can enable/disable whenever you want to debug specific code.

jecs​

</>
feces.jecs: jecs

The jecs module instance used by this library.

world​

</>
feces.world: World

The jecs.World instance this feces object observes and mutates.

replicated​

</>
feces.replicated: Entity

The replicated component id used to indicate per-entity player routing.

refs​

</>
feces.refs: {[number]: number}

Lookup table: lookupId -> localEntity for this group.

lookups​

</>
feces.lookups: {[number]: number}

Reverse lookup: localEntity -> lookupId for this group.

ref​

</>
feces:ref(
key: LookupEntity?,
group: Group?
) → LocalEntity

Find a local entity from a lookup id in group. Allocates a local entity if needed. Use feces.refs or group.refs if you simply want to check for a local entity.

lookup​

</>
feces:lookup(
entity: LocalEntity?,
group: Group?
) → LookupEntity

Resolve/allocate a lookup id and entity (if needed) in group. Find a lookup id for a local entity in group. Allocates a local entity if needed. Use feces.lookups or group.lookups if you simply want to check for a lookup id.

setGroup​

</>
feces:setGroup(
group: Group?,--

The group to assign (nil means default group)

entity: LocalEntity--

The local entity to move

) → ()

Assigns entity to group (or to the instance default group). Useful when you need to move an entity between replication namespaces. The implementation will update refs/lookups.

getGroup​

</>
feces:getGroup(entity: LocalEntity) → Group

Return the Group currently owning entity. If the entity is not assigned to a non-default group the result is the feces instance (default group).

delta​

</>
feces:delta(group: Group?) → (
Changes,
Deletes
)

Compute the pending changes and deletes for the provided group (or default). delta consumes internal buffers used to collect component changes; repeated calls without new changes return empty results. The result can be passed to combine for simple unified replication data.

full​

</>
feces:full(group: Group?) → Applyable

Produce a full replication packet for group (or default). This enumerates all currently replicated components and packages them into an Applyable suitable for sending to a player that needs the full current state for the group.

apply​

</>
feces:apply(
delta: Applyable,--

Packet to apply to the world.

group: Group?--

Apply using the group's lookup mapping; defaults to the instance group.

) → ()

Apply a replication packet to the local world. apply will create entities for lookup ids, call hooks (added, changed, removed, deleted) as appropriate, and perform jecs mutations.

debug​

</>
feces:debug(...: any) → ()

Internal debug function that prints only when feces._debug is truthy.
